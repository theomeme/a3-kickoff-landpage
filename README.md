# A3 Kickoff · Landing page

Landing page do gerenciador multicanal de e-commerce para quem vende no **Mercado Livre**, na **Amazon** e no **Enjoei**.

## O produto

Um painel único para o vendedor que anuncia nos três canais:

- **Estoque sincronizado:** vendeu a última unidade em um canal, os anúncios nos outros são pausados sozinhos.
- **Caixa unificado:** as vendas e os recebimentos dos três marketplaces em um só lugar.
- **Valor do estoque:** quanto dinheiro está parado em mercadoria, em R$.

## Objetivo da página

Apresentar o produto e captar os primeiros clientes do MVP 1.
